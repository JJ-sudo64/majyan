## r/playmygame (or r/WebGames) — "I made…"

**Title:** I made a free browser Riichi mahjong game where every character has a special skill — feedback welcome

**Body:**

Hi! I've been building Janhai, a 4-player Riichi mahjong game that runs in the browser (phone or PC, no download, no sign-up — just pick a name).

What's different from regular mahjong apps:
- 27 characters, each with one skill that fires when your gauge fills: stop time so you take two turns in a row, see everyone's hands for a turn, redraw your tile, flip an extra dora…
- Cards on top (one passive + one active per character, 82 in total) so the same character can play very differently.
- Ranked matches (rank points, promotion/demotion), friend matches with a passphrase, and a vs-CPU mode where every character and card is unlocked.
- There's a tutorial for people who've never played mahjong.

It's free to play. The UI is now available in English (the character voices are Japanese). The English translation is new, so I'd really like to hear about anything that reads wrong or is confusing.

Play: https://play-janhai.maxplantlabs.com/?lang=en
