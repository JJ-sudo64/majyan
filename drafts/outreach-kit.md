# 配信者・実況者向け 依頼キット

送信・投稿はあなたの操作です。相手の名前・配信内容に合わせて【　】を埋めてから送ってください。
押し付けにならないよう、「遊んでほしい」ではなく「使ってもいい」「見てもらえたら嬉しい」の温度で。

## 1. 誰に送るか（優先順）

1. 麻雀の配信・動画をしている**小〜中規模**（登録者〜数万）の人。大手より返信が来やすい。
2. 「ゲームを紹介する」系の個人実況者（無料ブラウザゲーム、インディー紹介）。
3. 麻雀系Vtuber。ネタ（異能×麻雀）と相性が良い。
4. 見つけ方: X で「麻雀 配信」「雀魂 配信」「麻雀 実況」を検索し、最近1か月以内に投稿している人を選ぶ。

**避けること**: 同文の一斉送信、返信が無い相手への再送、「拡散してください」の依頼、報酬をほのめかす文面。

## 2. DM / メール文（短め・基本形）

```
はじめまして。【あなたの名前 or 制作者】と申します。
【相手の配信/動画の具体的なところ】をいつも拝見していて、ご連絡しました。

個人で、異能麻雀ゲーム『雀杯』を作っています。
キャラごとの必殺技（時間停止・一閃など）が出る、4人打ちの麻雀です。
無料・登録不要で、ブラウザですぐ遊べます。

https://janhai.maxplantlabs.com

もしご興味があれば、配信や動画で使っていただいて構いません（事前の連絡も不要です）。
感想や改善点をいただけたら、とても助かります。
お忙しいところ失礼しました。
```

## 3. 返信用の補足（聞かれたら）

- 利用条件: 配信・動画での使用、収益化は自由。ただし規約・ライセンス上の注意があれば、公開前に確認してから伝える（**要確認**: 素材の二次利用ルールを公式ページに明記しているか）。
- 紹介用の素材: 縦動画 `drafts/shorts/play/` の各クリップ、スクリーンショット、ロゴ。
- 対応環境: ブラウザ（PC推奨、横向き画面）。

## 4. 送ったあとの運用

- 送信先と日付を1行ずつ記録（重複防止）: `drafts/outreach-log.md` を作って管理。
- 返信が無くても再送しない。1〜2週間後に、その人の別の配信に自然な形で反応するだけにする。
- 配信で使われたら、公式Xから感謝を一言＋引用で紹介（許可を得た人のみ）。

## 5. 事前に直しておくと効果が上がること

- 公式ページに「配信・動画での利用OK」の一文を入れる（相手が迷わない）。**入れる場合は私が公式ページに追記します。**
- 初見の人が詰まらない導線（「すぐ遊ぶ」ボタン → CPU戦）になっているか、自分で一度シークレットウィンドウで確認する。
