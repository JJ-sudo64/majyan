## TikTok
- 登録: スマホアプリで。ビジネス用でなく普通のアカウントでよい。プロフィールのリンク欄は、フォロワー数などの条件で出ないことがある（その間は自己紹介文のURLを使う）。

```

## YouTube Shorts
- 登録: Googleアカウントでチャンネルを作る（チャンネル名 `雀杯【公式】`）。
- 投稿: スマホの「＋」→「動画をアップロード」でもOK。60秒以内の縦動画は自動でShortsになる。
- タイトルの型（100文字以内）:
```
【{キャラ名}】必殺技「{必殺技名}」 #Shorts #雀杯 #異能麻雀
```
- 説明欄:
```

▼今すぐ遊ぶ https://janhai.maxplantlabs.com

## Instagram Reels
- 登録: アカウント作成後、プロフィール設定で「プロアカウントに切り替え」（任意）。
- キャプション: TikTokと同じ。リンクはプロフィールに1つだけ貼れる。
- 動画は「リール」として投稿し、フィードにも共有をオンにする。

## 共通の注意
- **絵やボイスが生成AIで作られている場合は、各サービスの開示設定（AI生成コンテンツのラベル）を付ける。** TikTok・YouTube・Instagramに設定項目がある。付け忘れると削除や制限の原因になる。
- 動画内の音（BGM・ボイス・効果音）は、このゲーム用に用意したものだけを使っている。外の楽曲は入れていない。
- 反応が出た動画の型（キャラ紹介／時間停止系など）を、1週間後に見直す。
