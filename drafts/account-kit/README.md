## 毎日の投稿
- `drafts/post-calendar.md` の Day 1（ゼノ）から順に、毎日1本。動画は `drafts/shorts/chars/{id}.mp4`。
- 時間帯は夜（20〜23時）に固定すると、あとで反応の違いを比べやすい。

## 反応があった時の返信テンプレ
- 感想をもらった: 「ありがとうございます！よければ遊んでみてください → https://janhai.maxplantlabs.com」
- キャラの話題: 「{キャラ名}、いいですよね。必殺技は『{必殺技名}』です」
- 不具合の報告: 「ご報告ありがとうございます。確認します。端末とブラウザを教えてもらえると助かります」
