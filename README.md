# 雀 - 対戦型麻雀（開発中）

雀魂のようなネット対戦麻雀＋キャラクター必殺技を目指すプロジェクトの第1マイルストーン。
現在は「ローカルで1人プレイヤー + 3人CPUと東風戦/半荘戦を最後まで打てるWeb UI」までを実装済み。

## 構成

- `packages/core` — 麻雀ルールエンジン（牌・役判定・点数計算・ゲーム進行・簡易CPU）。UI非依存の純粋なTypeScript。
- `packages/web` — Vite + React のフロントエンド。`packages/core` を利用してブラウザ上で対局できる。
- `packages/server` — ネット対戦サーバー（Node + WebSocket）。`packages/core` を共有し、本物の対局状態はサーバーだけが持つ。

## セットアップ

```
npm install
```

## 開発

```
npm run dev          # web の開発サーバーを起動 (http://localhost:5173)
npm run dev:server   # ネット対戦サーバーを起動 (ws://localhost:8787/ws、web からは /ws で中継される)
npm test              # core / server のユニットテスト
npm run typecheck     # core / web / server の型チェック
```

### ネット対戦（友人戦）を試す

1. `start-game.bat` をダブルクリック（ゲームサーバーと画面を両方起動する）。または `npm run dev:server` と `npm run dev` を両方起動する
2. 「プレイ」→「オンライン（段位戦・ガチャ・友人戦）」で名前を決め（初回だけ。ゲストアカウントがこのブラウザに保存される）、合言葉を入れて部屋に入る
3. 同じ合言葉の人が集まったら部屋主（最初に入った人）が開始する。空いた席は CPU が入る

打牌・鳴きには制限時間（毎回5秒＋持ち時間20秒）があり、切れると自動でツモ切り／見送りになる。
対局中に接続が切れても、同じアカウント（同じブラウザ）で同じ合言葉の部屋に入り直せば同じ席に戻れる。

### 段位戦

「オンライン」画面の「段位戦」から東風戦／半荘戦の待ち行列に並ぶと、段位の近い4人で卓が組まれる。
4人そろわないまま一定時間（既定20秒、`RANKED_CPU_FILL_MS`）たつと、空いた席を CPU で埋めて始まる。
段位は 下雀 → 中雀 → 上雀 → 雀王 → 雀帝（各1〜3段）→ 雀神。ポイントは順位と終局時の持ち点で増減し、
数値はすべて `packages/core/src/ranked.ts` にまとまっている。段位戦は途中で全員抜けても最後まで自動で打ち切られ、結果が段位に反映される。

### 公開する（友人に遊んでもらう）

本番ではサーバー1つが画面と WebSocket の両方を配る。

```
npm start                     # 画面をビルドして http://localhost:8787 で起動
docker build -t majyan .      # もしくはコンテナで
docker run -p 8787:8787 -v majyan-data:/data -e DATABASE_PATH=/data/majyan.db -e ALLOWED_ORIGINS=https://自分のURL majyan
```

環境変数: `PORT`（既定8787）、`ALLOWED_ORIGINS`（接続を許すページのURL、カンマ区切り。公開時は必ず設定）、
`STATIC_DIR`（画面のビルド結果の場所）、`DATABASE_PATH`（アカウント等を保存する SQLite ファイル。
既定 `packages/server/data/majyan.db`。コンテナでは消えない場所＝ボリュームに置く）、
`TRUST_PROXY=1`（リバースプロキシの後ろに置く時。接続元の判定に X-Forwarded-For を使う）。
アカウントはデータベースに残るが、部屋・対局はメモリ上だけにあるので、サーバーを再起動すると消える。
HTTPS は前段（ホスティングサービスやリバースプロキシ）で終端する想定。

## 実装済みのスコープ

- 四人打ち、東風戦／半荘戦選択制
- 主要な役一通り（リーチ〜国士無双・四暗刻・大三元等の役満まで）、符・翻計算
- チー・ポン・カン（暗槓/明槓/加槓）・リーチ・ロン・ツモ・九種九牌流局・荒牌平局
- シャンテン数ベースの簡易CPU（安全牌への簡易ベタオリ込み）
